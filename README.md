# 日本語入力支援アプリ（タブレット向け PWA）

構音障害があり、指先でのタッチ操作も難しい方が日本語で意思を伝えるための入力支援アプリです。50音を「行 → 段」の2段階で選んで文を作り、音声で読み上げます。

入力方式は2つあり、設定で切り替えます。

- **方向キー入力**: 方向キーでカーソルを動かして選ぶ。狙った位置をある程度押せる方向け
- **スキャン入力**: 候補が順に光り、目的の候補が光ったときに大きな確定ボタンを押して選ぶ。手の震えなどで狙った位置を押すのが難しい方向け

- 公開URL: https://showtime2002.github.io/ipad-enhanced-JPN-IF/
- 対象端末: iPad（Safari）、Android 端末（Chrome、動作確認済み）。いずれもホーム画面に追加して使用。iPhone（SE 含む）でも表示可能
- 構成: HTML 1ファイルで動作。ビルド不要、外部ライブラリなし

## 使い始め方

iPad（Safari）:

1. Safari で公開URLを開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動する（全画面表示になる）

Android 端末（Chrome）:

1. Chrome で公開URLを開く
2. 右上のメニュー（︙）→「ホーム画面に追加」または「アプリをインストール」
3. ホーム画面のアイコンから起動する（全画面表示になる）

一度開けば、以降はオフラインでも起動できます（Service Worker によるキャッシュ）。

### 更新が反映されないとき

新しい版は、アプリを開き直したときに読み込まれます。ホーム画面から起動したアプリは、閉じたつもりでも裏で動き続けていることがあり、その場合は古い版のままになります。

- Android: 履歴ボタン（□ または画面下から上へスワイプして止める）でアプリの一覧を出し、このアプリを上へはじいて完全に終了してから開き直す
- iPad: 画面下から上へスワイプして止め、このアプリを上へはじいて完全に終了してから開き直す

## 方向キー入力

### 画面構成

画面は上・中・下の3段で、スクロールせずに1画面に収まります。

| 領域 | 内容 |
|---|---|
| 上段: 入力エリア | 入力した文の表示欄（文字の選択・コピー可）、ステータス表示、設定ボタン |
| 中段左: 行選択パネル | あ〜わ の10行、「゛゜小」（変換キー）、「記号」。3列×4行 |
| 中段右: 段選択パネル | 選んだ行の5文字を十字に配置（中央=あ段、左=い段、上=う段、右=え段、下=お段） |
| 下段: 方向キー | 8方向キー、中央の「確定」、操作ボタン5つ |

行選択パネルの並び:

```
あ      か      さ
た      な      は
ま      や      ら
゛゜小  わ      記号
```

いま行選択と段選択のどちらを操作しているかは、パネルの枠の色（カーソル色）とステータス表示で分かります。

### 方向キーで入力する

1. 起動時は「行選択」状態で、カーソルは「な」（中央＝ホームポジション）にある
2. 方向キーでカーソルを動かし、目的の行で「確定」を押す →「段選択」状態になる
3. 方向キーで段を選び「確定」を押す → 文字が入力され、行選択（「な」）に戻る

### 直接タッチで入力する

- 行パネルのセルをタッチ → その行を選択する（段パネルの表示が切り替わる）
- 段パネルのセルをタッチ → その文字をすぐ入力する（確定ボタン不要）

### 濁点・半濁点・小文字（゛゜小）

直前に入力した1文字を変換します。

1. 行パネルで「゛゜小」を選んで確定する（入力が空のときは無効）
2. 段パネルに変換候補が出る: 左=濁点、上=半濁点、右=小文字、中央・下=変換しない（候補がないものは「ｘ」）
3. 目的の候補で確定する（または候補をタッチする）

| 変換 | 対象 |
|---|---|
| 濁点 | か・さ・た・は行、う → ゔ |
| 半濁点 | は行 |
| 小文字 | あ行、つ、や行、わ |

### 記号（句読点）

行パネルの「記号」を選ぶと、段パネルに句読点が出ます（中央=「、」、左=「。」、上=「？」）。

### わ行・長音「ー」と「ｘ」

わ行は中央=「わ」、左=「を」、上=「ん」、右=「ー」（長音）です。長音は方向キーでも直接タッチでも入力できます。

文字のない位置には「ｘ」が表示されます（や行の左右、わ行の下、記号の右・下、゛゜小で変換できない候補）。「ｘ」を選んでも何も入力されません。

### 操作ボタン

| ボタン | 動作 |
|---|---|
| 読み上げ | 入力内容を日本語音声で読み上げる（端末の音声合成を使用） |
| 削除 | 最後の1文字を削除する |
| ↺ | 段選択中・変換選択中: 行選択に戻る／行選択中: 最後の1文字を取り消し、直前に確定した行の段選択に戻る |
| クリア | 入力内容をすべて消去する（確認なし） |
| 空白 | 半角スペースを入力する |

## スキャン入力

詳しい仕様は [docs/scan-input-spec.md](docs/scan-input-spec.md) を参照してください。

### 画面構成

上から、入力エリア、行パネル、段パネル、確定ボタン（画面下部）の順に並びます。確定ボタンの左右には、横幅15%のリバースボタン（◀◀）があります。本人は確定ボタンとリバースボタンで操作します。

```
あ    か    さ    た    な
は    ま    や    ら    わ
゛゜小 記号  機能
```

### 入力のしかた

1. 確定ボタンを押すとスキャンが始まる（起動直後と、設定画面を閉じた後は待機状態）
2. 行パネルの候補が「あ」から順に光る。目的の行が光っている間に確定ボタンを押す
3.「か行、ですね？」と音声で確認される。読み上げが終わってから確認待ち時間内に、もう一度確定ボタンを押すと決まる。押さなければ取り消され、1つ前の候補から光り直す
4. 段パネルに「か き く け こ 戻る」が並び、1秒おいてから順に光る。目的の文字で確定ボタンを押す
5.「く、ですね？」と確認される。もう一度押すと入力欄に「く」が追加され、行パネルの「あ」から光り直す

光っている候補は太い枠と黄色の背景で示し、下端のバーで残り時間を示します。音声確認中の候補は塗りつぶしで示します。

### 特別な行

| 行 | 段パネルの候補 |
|---|---|
| や行 | や ゆ よ |
| わ行 | わ を ん ー |
| ゛゜小 | 直前の1文字の変換候補（濁点・半濁点・小文字のうち変換できるもの）。候補がないときは「変換できる文字がありません」と読み上げる |
| 記号 | 、 。 ？ |
| 機能 | 読み上げ 削除 空白 クリア |

段パネルの最後の「戻る」を選ぶと、行選択に戻ります。

### リバースボタン（◀◀）

確定ボタンを押すのが遅れて目的の候補を通り過ぎたときに使います。左右どちらも同じ動作です。

- 1回押す: 光っている候補を2つ前に戻す（先頭の候補より前は末尾に回る）
- 続けてもう1回押す（0.5秒以内のダブルタップ）: 先頭の候補に戻す
- 音声確認中に押すと、選んだ候補を取り消して、その2つ前（ダブルタップなら先頭）から光り直す

### パネルのタッチ（介助者向け）

光るのを待たずに、パネルを直接タッチして選ぶこともできます（設定の「パネルのタッチ」で無効にできます）。

- 行パネルをタッチ: 音声確認なしで、すぐにその行の段スキャンに進む（例:「機能」をタッチして、すぐに機能パネルを出す）
- 段パネルをタッチ: 「クリア、ですね？」と音声確認し、確定ボタンで決まる（本人の誤タッチで入力やクリアが起きないようにするため）

段パネルのタッチは、段スキャン中だけ有効です（行スキャン中のプレビュー表示はタッチしても反応しません）。

### 誤操作への対策

- 確定ボタンは指が触れた瞬間に反応する（指が動いても取りこぼさない）
- 押した直後の一定時間（連打防止時間）は、次の押下を無視する
- 確認の音声が流れている間の押下は無視する
- 3周続けて押されなければ一時停止し、「確定で再開」と表示する
- 設定画面を開いたとき、アプリが裏に回ったときはスキャンを止める

### 外部スイッチ

Bluetooth 接続の外部スイッチを、キーボードとして Space または Enter を送る設定で接続すると、スイッチで確定できます。

## 設定

「設定」ボタンで開きます。設定は端末に保存され、次回起動時も引き継がれます。

| 項目 | 選択肢 | 影響範囲 |
|---|---|---|
| 入力方式 | 方向キー／スキャン（既定: 方向キー） | 画面と操作方法 |
| ボタンサイズ | 標準／大／特大 | 行・段パネルのセルと操作ボタンの高さ |
| 文字サイズ | 標準／大／特大 | 入力表示欄、パネル、操作ボタンの文字 |
| カーソル色 | 青／緑／赤／オレンジ | 選択中のセルと操作中パネルの枠、スキャンの強調色、確定ボタン |
| スキャン間隔 | 0.5〜5.0秒（既定: 2.0秒） | 1つの候補が光っている時間 |
| 確認待ち時間 | 1.0〜5.0秒（既定: 2.0秒） | 音声確認の後、決定を受け付ける時間 |
| 連打防止 | 0.3〜1.0秒（既定: 0.5秒） | 押した直後に次の押下を無視する時間 |
| 無操作で停止 | 2〜5周／しない（既定: 3周） | 押されないまま何周したら一時停止するか |
| パネルのタッチ | 有効／無効（既定: 有効） | スキャン中に行・段パネルを直接タッチして選べるか |

スキャン間隔から下の5項目は、入力方式がスキャンのときだけ表示されます。ボタンの高さは画面の高さに合わせて自動で調整され、上限は設定値で決まります。

## 画面の消灯防止（共通）

アプリを開いている間は、操作がなくても画面が暗くならないようにしています（Screen Wake Lock）。端末の省エネ設定そのものは変更しません。アプリを閉じる・ホーム画面に戻る・別のアプリに切り替えると自動で解除され、端末の設定どおりの動作に戻ります。

- 端末が低電力モード（省電力モード）のときは、端末側の判断で消灯防止が効かないことがあります
- 対応: Android の Chrome、iPad の Safari（iPadOS 16.4 以降。ホーム画面から起動する場合は iPadOS 18.4 以降）

## 誤操作への対策（共通）

- ピンチ拡大・ダブルタップ拡大・スクロール・スワイプを無効化
- 長押しメニューと文字選択を無効化（入力表示欄を除く）
- 画面の高さに合わせてボタンの高さを自動調整（1画面に収まるレイアウト）

## データの保存

入力内容と設定は、ブラウザの localStorage に保存されます（キー: `jp-access-input-text`, `jp-access-settings`）。サーバーへの送信はありません。アプリを閉じても入力内容は残ります。

## 開発・公開

- ローカル確認: `python3 -m http.server 8000` を実行し、http://localhost:8000/ を開く
- 公開: GitHub Pages（main ブランチのルート）。**main に push すると、すぐに本番に反映されます**
- キャッシュ: `sw.js` は HTML をネットワーク優先、それ以外をキャッシュ優先で配信します。`manifest.json` や `icon.svg` を変更したら `CACHE_NAME` のバージョンを上げてください

## 既知の課題

- `apple-touch-icon` が SVG のため、iOS のホーム画面アイコンが正しく表示されない可能性がある（iOS は PNG のみ対応）
- 方向キー入力: 「クリア」に確認がなく、押し間違えると入力内容がすべて消える（スキャン入力では音声確認がある）
